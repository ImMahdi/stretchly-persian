> [!NOTE]
> ### 🔗 درباره این فورک و پروژه اصلی
> **Stretchly Persian** یک نسخه بازطراحی‌شده، بومی‌سازی‌شده و بهبودیافته از نرم‌افزار محبوب و متن‌باز [Stretchly](https://github.com/hovancik/stretchly) اثر [Jan Hovancik](https://github.com/hovancik) است. 
> 
> هدف این فورک، ارائه یک تجربه کاربری مدرن، تمیز، کاملاً فارسی و سازگار با سیستم‌عامل‌های امروزی (ویندوز ۱۱ و مک)، ادغام فونت استاندارد وزیرمتن و همچنین امکان مدیریت و شخصی‌سازی فوق‌العاده ساده‌ی جملات و تمرینات استراحت بدون نیاز به پیچیدگی‌های فنی است.
> 
> برای مشاهده مستندات مرجع، تاریخچه کلی و توضیحات کامل نسخه اصلی انگلیسی می‌توانید به [مخزن رسمی Stretchly](https://github.com/hovancik/stretchly) مراجعه نمایید.

## ✨ ویژگی‌های برجسته این فورک (Features & Enhancements)

### 🎨 ۱. بازطراحی کامل و مینیمال پنجره تنظیمات (Preferences UI Redesign)
* **چیدمان کارتی استاندارد (Card-based Layout)**: تمامی گزینه‌ها در کارت‌های تفکیک‌شده و منظم سازمان‌دهی شده‌اند.
* **سوییچ‌های تعاملی مدرن**: جایگزینی کامل چک‌باکس‌های قدیمی با کلیدهای Toggle نرم، مدرن و هماهنگ با سیستم‌عامل‌های روز.
* **پالت‌های رنگی دایره‌ای زیبا**: انتخاب رنگ‌های آرامش‌بخش برای پنجره‌های استراحت با اندیکاتور فعال جذاب.
* **رابط صوتی ارتقایافته**: دکمه‌های Play مدرن با انیمیشن پالس برای پیش‌شنوایی لحظه‌ای زنگ‌های استراحت.
* **غیرفعال‌سازی هوشمند کارت‌ها**: با خاموش کردن استراحت‌های کوتاه یا طولانی، کادر تنظیمات آن به صورت خودکار و بصری کم‌رنگ و غیرفعال می‌شود.
* **طراحی بدون مزاحمت**: حذف کامل پاپ‌آپ‌ها و بنرهای دونیت/پتریون و تمرکز ۱۰۰٪ بر آرامش کاربر.

### 🇮🇷 ۲. بومی‌سازی عمیق و راست‌چین پایدار (Full RTL & Persian Typography)
* **فونت چشم‌نواز وزیرمتن (Vazirmatn)**: بارگذاری فونت محلی وزیرمتن برای تمامی پنجره‌ها و متن‌ها.
* **چیدمان راست‌به‌چپ (RTL) استاندارد**: تنظیم دقیق موقعیت اسلایدرها، تراز برچسب‌ها، منوهای کشویی و نوار ناوبری متناسب با زبان فارسی.
* **ترجمه ۱۰۰٪ روان**: ترجمه بازبینی‌شده و منسجم تمامی پیام‌ها، اعلان‌ها و منوی کنار ساعت (System Tray).

### 💡 ۳. تب اختصاصی «جملات و تمرین‌ها» (Ideas & Exercises Tab)
* **ادیتور ساده و دم دست**: داخل پنجره تنظیمات یک تب اختصاصی برای ویرایش جملات استراحت‌های کوتاه و تمرینات استراحت طولانی قرار گرفته است.
* **فرمت ساده و کاربرپسند**:
  * **استراحت کوتاه**: هر خط = یک جمله یا توصیه سلامتی (مثال: `یک لیوان آب بنوشید.` یا `چند نفس عمیق بکشید.`).
  * **استراحت طولانی**: هر خط = `عنوان | توضیحات` (مثال: `قدم زدن | چند دقیقه در اتاق راه بروید`).
* **شمارنده لحظه‌ای**: نمایش زنده تعداد جملات و تمرینات فعال با تایپ در کادرها.
* **ذخیره آنی (Hot-Reload)**: با زدن دکمه ذخیره، تغییرات بدون نیاز به راه‌اندازی مجدد برنامه بلافاصله اعمال می‌شوند.
* **همگام‌سازی با فایل‌های متنی**: فایل‌های `microbreak-ideas.txt` و `longbreak-ideas.txt` همواره با ادیتور سینک بوده و دکمه **«باز کردن در نوت‌پد 📝»** نیز برای ویرایش متنی خارج از برنامه تعبیه شده است.
* **همگام‌سازی هوشمند با تغییر زبان**: با تغییر زبان برنامه، جملات پیش‌فرضِ همان زبان به صورت خودکار در ادیتور لود می‌شوند.
* **دکمه بازنشانی امن**: امکان بازگردانی آسان تمامی جملات به حالت پیش‌فرض اولیه در هر زمان.

### 🚀 ۴. اتصال مستقیم سیستم بررسی آپدیت به گیت‌هاب (Direct GitHub Releases)
* دیگر نیازی به راه‌اندازی سرور، وب‌سایت یا هاست شخصی برای بررسی نسخه‌های جدید نیست.
* برنامه به صورت مستقیم از طریق GitHub API رسمی مخزن [ImMahdi/stretchly-persian](https://github.com/ImMahdi/stretchly-persian) انتشار نسخه‌های جدید را بررسی می‌کند.
* کنترلر بررسی آپدیت در تب «درباره برنامه» با تیتر شفاف، توضیحات گویا و کلید خاموش/روشن اختصاصی طراحی شده و در صورت نبود نسخه جدید، با برچسب آرامش‌بخش **«به‌روز است»** کاربر را مطمئن می‌سازد.

## 🧭 ریتم استراحت‌ها و شیوه کارکرد

Stretchly بر پایه اصول ارگونومی و تکنیک‌های استاندارد سلامت کار با مانیتور کار می‌کند:

```
  ┌────────────────────────────────────────────────────────┐
  │  کار با سیستم (۱۰ دقیقه)                                │
  └───────────────────────────┬────────────────────────────┘
                              │
                              ▼
  ┌────────────────────────────────────────────────────────┐
  │  ☕ استراحت کوتاه (Microbreak - ۲۰ ثانیه)               │
  │  نگاه به نقطه دور، استراحت به چشم، پلک زدن             │
  └───────────────────────────┬────────────────────────────┘
                              │  (تکرار چند نوبت)
                              ▼
  ┌────────────────────────────────────────────────────────┐
  │  🚶 استراحت طولانی (Long Break - ۵ دقیقه)                │
  │  بلند شدن از صندلی، حرکات کششی، نوشیدن آب، قدم زدن     │
  └────────────────────────────────────────────────────────┘
```

> [!TIP]
> تمامی فواصل زمانی (مدت کار، مدت استراحت کوتاه، مدت استراحت طولانی) و حتی فعال یا غیرفعال بودن هرکدام از بخش پنجره تنظیمات قابل شخصی‌سازی کامل است.

## ⌨️ کلیدهای میانبر (Shortcuts)

شما می‌توانید با استفاده از کلیدهای میانبر زیر، بدون نیاز به باز کردن منوها استرچلی را کنترل کنید:

| کلید میانبر (Shortcut) | عملکرد |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd> | پرش از استراحت فعلی (Skip Break) |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>P</kbd> | به تعویق انداختن استراحت فعلی (Postpone) |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd> | شروع فوری یک استراحت کوتاه |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd> | شروع فوری یک استراحت طولانی |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>M</kbd> | توقف موقت / ادامه یادآوری‌ها (Pause / Resume) |

*(کلیدهای میانبر در تب تنظیمات به دلخواه شما قابل تغییر هستند)*

## 🛠️ راهنمای توسعه‌دهندگان (Development & Build)

اگر مایل به توسعه یا بیلد این نسخه از سورس‌کد هستید:

### ۱. نیازمندی‌ها
* [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر)
* `npm`

### ۲. دریافت سورس و نصب وابستگی‌ها
```bash
# کلون کردن مخزن
git clone https://github.com/ImMahdi/stretchly-persian.git
cd stretchly-persian

# نصب پکیج‌ها
npm install
```

### ۳. اجرای برنامه در حالت توسعه (Dev Mode)
```bash
npm run dev
# یا
npm start
```

### ۴. اجرای تست‌ها و اعتبارسنجی استایل کد
```bash
# اجرای ۳۴۵ تست واحد پروژه (Vitest)
npm test

# بررسی و اعتبارسنجی استایل جاوااسکریپت (Standard JS)
npx standard
```

### ۵. ساخت خروجی اجرایی ویندوز (Build Executable)
```bash
npx electron-builder build --win dir --config.npmRebuild=false
```
فایل‌های خروجی در پوشه `dist/win-unpacked/` قرار خواهند گرفت.
